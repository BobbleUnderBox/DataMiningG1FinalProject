🔧 異常值處理策略（重點決定）
=============================================================

【核心原則】保留 + 變換（不盲目刪除）

| 字段 | 為什麼保留 | 處理方法 | 檢定前提 |
|------|----------|--------|--------|
| monthly_income | 極端富有樣本有效 | Log 變換 | 正態性 |
| repayment_delay_days | 長期逾期有業務意義 | Robust Scaling | 等方差性 |
| debt_to_income_ratio | 高杠杆樣本確實存在 | Robust Scaling | 線性性 |
| risk_score | 複合指標，極值有預測力 | 標準化 | 可靠性 |

【應對檢定前提】
- 線性模型: Log/Box-Cox 變換 + Robust Scaling
- 樹模型: 自動處理，建議做 Log 變換改善穩定性
- 診斷: Shapiro-Wilk (正態性) + Levene (等方差性)

📚 使用流程速查
=============================================================

1️⃣ 首次設置
   $ make install              # 安裝依賴
   $ make data                 # 下載資料

2️⃣ 在 Notebook 中使用
   from src.data_loader import load_data
   df = load_data()            # 一行代碼

3️⃣ 完成分析後
   loader.save_interim_data(df, "01_output.csv")

4️⃣ 常用命令
   $ make eda                  # EDA
   $ make preprocess           # 預處理
   $ make train                # 訓練
   $ make test                 # 測試
   $ make format               # 格式化
